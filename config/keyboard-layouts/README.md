# Flagged macOS input sources

This bundle provides two user-level keyboard layouts with country-flag icons:

- `Dvorak – QWERTY ⌘ US` is cloned from Apple's built-in Dvorak–QWERTY Command input source.
- `Ukrainian-PC UA` uses the established Ukrainian-PC mapping.

Install the matching `.keylayout` and `.icns` files directly in `~/Library/Keyboard Layouts`, log out and back in, then add both layouts in System Settings → Keyboard → Text Input → Edit. The bundle is retained as the editable source collection.

The original Apple input sources can remain enabled until the replacements have been tested.
